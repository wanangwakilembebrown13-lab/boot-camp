Python is one of the most readable programming languages in the world. Its syntax is close to plain English, which makes it a perfect first language. Let's start with the building blocks.

Your first line of Python

print("Hello, Malawi!")

That's it. No semicolons, no main function, no compilation. Save it to a .py file and run it with python hello.py. Here in the browser editor, just click Run.

Variables

In Python you assign a value to a name with the = sign. No need to declare the type — Python figures it out.

name = "Chisomo"
age = 22
height = 1.75
is_student = True

Naming convention: snake_case for variables and functions. Uppercase for constants (MAX_SIZE = 100).

The four core data types

  • str — text in quotes: "hello", 'world'
  • int — whole numbers: 42, -7, 0
  • float — decimal numbers: 3.14, -0.5
  • bool — True or False (capital first letter!)

Checking the type

Use type() to ask Python what something is:

print(type(name))      # <class 'str'>
print(type(age))       # <class 'int'>
print(type(3.14))      # <class 'float'>
print(type(True))      # <class 'bool'>

Converting between types

number = int("42")     # string to int
text = str(42)         # int to string
decimal = float("3.14")
Python is strongly typed: "5" + 5 raises an error, unlike JavaScript. You must convert explicitly. This prevents a huge class of bugs.

Text is everywhere in Python. Learning to work with strings is 30% of day-to-day programming.

f-strings (your new best friend)

Prefix a string with f and put variables inside { }:

name = "Chisomo"
age = 22
print(f"My name is {name} and I am {age} years old.")

You can put any expression inside the braces:

print(f"Next year I will be {age + 1}.")

Common string methods

text = "  Hello World  "

print(text.strip())        # "Hello World"
print(text.upper())        # "  HELLO WORLD  "
print(text.lower())        # "  hello world  "
print(text.replace("World", "Malawi"))
print(text.split())        # ['Hello', 'World']

Getting input from the user

input() always returns a string. Convert it if you need a number:

name = input("What is your name? ")
age = int(input("How old are you? "))
print(f"Hello {name}, you are {age} years old.")
In this browser editor, input() opens a small dialog box. In a real terminal it just waits for typing.

String formatting (the old way, still useful)

price = 2500
print("Price: {} KMW".format(price))
print("Price: %d KMW" % price)

Prefer f-strings in new code — they're the clearest and fastest.

Multi-line strings

message = """This is a
multi-line string.
It preserves line breaks."""
print(message)

Programs need to make decisions. Python makes this remarkably readable with if, elif, and else.

Basic if / else

age = 20

if age >= 18:
    print("You may enter.")
else:
    print("Sorry, you are too young.")

Notice two things that are unique to Python:

  • The colon : at the end of each condition
  • The indentation (usually 4 spaces) that marks the block

There are no curly braces. Indentation is the syntax.

elif — the middle branch

score = 75

if score >= 80:
    grade = "A"
elif score >= 70:
    grade = "B"
elif score >= 60:
    grade = "C"
else:
    grade = "F"

print(f"Grade: {grade}")

Python checks each condition top to bottom, running the first one that is True.

Comparison operators

  • == — equal to
  • != — not equal
  • <, >, <=, >= — less / greater than

Logical operators

Python uses plain words instead of symbols:

age = 20
has_id = True

if age >= 18 and has_id:
    print("You may enter.")

if age < 13 or age > 65:
    print("Discount applies.")

if not has_id:
    print("You need ID.")

Truthiness

Some values are automatically False in a boolean context: 0, 0.0, "", [], {}, None. Everything else is True.

name = ""

if name:
    print(f"Hello {name}")
else:
    print("Name is empty")
Python's use of and, or, not instead of &&, ||, ! is one of the reasons it reads like English.

Loops let you repeat work. Python has two kinds: for (for iterating) and while (for repeating until a condition changes).

for loops with range()

for i in range(5):
    print(i)

This prints 0 1 2 3 4. range(5) produces 0,1,2,3,4 — starting at 0, ending before 5.

for i in range(1, 6):
    print(i)

Now it prints 1 2 3 4 5. range(start, stop) includes start but excludes stop.

for i in range(0, 10, 2):
    print(i)

Prints 0 2 4 6 8. The third argument is the step.

Looping over a list

fruits = ["apple", "banana", "mango"]
for fruit in fruits:
    print(fruit)

You almost never need the index when looping in Python. Just iterate over the values directly.

If you need the index

for i, fruit in enumerate(fruits):
    print(f"{i + 1}. {fruit}")

while loops

count = 0
while count < 5:
    print(count)
    count += 1

Use a while loop when you don't know how many iterations you need — only when to stop.

break and continue

for n in range(10):
    if n == 5:
        break         # exit the loop entirely
    print(n)

for n in range(5):
    if n == 2:
        continue      # skip the rest of this iteration
    print(n)
Infinite loops: if you write while True: with no break inside, your program runs forever. Make sure every while loop has a way to end.

Functions let you package up code, give it a name, and reuse it. Python's function syntax is clean and readable.

Defining a function

def greet(name):
    return f"Hello, {name}!"

message = greet("Chisomo")
print(message)

Parts of a function:

  • def — the keyword that starts a function definition
  • greet — the function name (snake_case)
  • (name) — the parameter list
  • Colon : and indented body
  • return — sends a value back (optional — if missing, the function returns None)

Default arguments

def greet(name, greeting="Hello"):
    return f"{greeting}, {name}!"

print(greet("Chisomo"))               # "Hello, Chisomo!"
print(greet("Chisomo", "Moni"))       # "Moni, Chisomo!"

Keyword arguments

When calling, you can name the parameters to make the call clearer:

def describe(name, age, city):
    return f"{name}, {age}, from {city}"

print(describe(city="Lilongwe", name="Chisomo", age=22))

Returning multiple values

def min_max(numbers):
    return min(numbers), max(numbers)

low, high = min_max([3, 1, 7, 2, 9])
print(low, high)   # 1 9

Python actually packs them into a tuple and unpacks on the way out.

Scope

Variables created inside a function are local — they disappear when the function ends:

def example():
    x = 10
    print(x)

example()       # 10
print(x)        # NameError: name 'x' is not defined
Name your functions like verbs: calculate_total, format_date, is_valid_email. Not stuff or fn1.

Real programs crash. Learning to import modules and handle errors gracefully is what separates toy code from production code.

Importing modules

import math
import random
import json

print(math.sqrt(16))          # 4.0
print(math.pi)                # 3.14159...
print(random.randint(1, 10))  # a random number

From imports

If you only need one thing, import just that:

from math import sqrt, pi
print(sqrt(25))    # 5.0

What is an exception?

When Python hits something it can't do, it "raises" an exception and stops. Common ones:

  • ValueError — right type, wrong value: int("hello")
  • TypeError — wrong type: "5" + 5
  • NameError — using an undefined variable
  • ZeroDivisionError — 10 / 0
  • KeyError — looking up a missing dict key
  • FileNotFoundError — opening a file that doesn't exist

try / except

try:
    age = int(input("Your age: "))
    print(f"In 10 years you'll be {age + 10}")
except ValueError:
    print("That was not a valid number.")

The try block runs normally. If an exception is raised, Python jumps straight to the except block.

Catching specific exceptions

try:
    numbers = [1, 2, 3]
    print(numbers[10])
except IndexError:
    print("That index does not exist.")

try:
    result = 10 / 0
except ZeroDivisionError:
    print("Cannot divide by zero.")

finally — always runs

try:
    f = open("data.txt")
    print(f.read())
except FileNotFoundError:
    print("File not found.")
finally:
    print("Done trying.")
Only catch exceptions you can actually handle. Writing a bare except: hides bugs — always catch a specific exception type.

Lists are Python's workhorse data structure. Mastering them is essential — you'll use them in every project.

Creating lists

numbers = [10, 20, 30, 40]
names = ["Chisomo", "Tadala", "Gift"]
mixed = [1, "hello", 3.14, True]

Accessing items

print(numbers[0])       # 10  (first item)
print(numbers[-1])      # 40  (last item)
print(numbers[1:3])     # [20, 30]  (slice, end-exclusive)

Negative indexes count from the end. Slices are list[start:stop] — stop is excluded.

Modifying lists

numbers.append(50)      # add to end
numbers.insert(0, 5)    # insert at index 0
numbers.remove(20)      # remove first occurrence of 20
last = numbers.pop()    # remove & return last
numbers[0] = 99         # replace at index 0

Useful operations

print(len(numbers))     # length
print(sum(numbers))     # sum
print(min(numbers))     # smallest
print(max(numbers))     # largest
print(sorted(numbers))  # new sorted list
print(20 in numbers)    # True / False

Looping

for n in numbers:
    print(n)

for i, n in enumerate(numbers):
    print(f"{i}: {n}")

List comprehensions

A Pythonic way to build a list in one line:

squares = [n * n for n in range(1, 6)]
# [1, 4, 9, 16, 25]

evens = [n for n in range(10) if n % 2 == 0]
# [0, 2, 4, 6, 8]

Tuples — immutable lists

point = (10, 20)
x, y = point          # unpacking
# point[0] = 99       # ERROR — tuples can't be modified

Use tuples for values that shouldn't change (coordinates, RGB colors, records).

Dictionaries map keys to values. If you remember one data structure from this course, make it this one.

Creating dictionaries

user = {
    "name": "Chisomo",
    "age": 22,
    "city": "Lilongwe"
}

scores = {"math": 85, "english": 92}

Accessing and modifying

print(user["name"])         # "Chisomo"
user["age"] = 23            # update
user["email"] = "c@m.mw"    # add new key

print(user.get("phone"))    # None (safe)
print(user.get("phone", "no phone"))   # fallback

Use .get() when a key might not exist — it returns None or a default instead of crashing.

Looping over a dict

for key in user:
    print(key, "=", user[key])

for key, value in user.items():
    print(f"{key}: {value}")

for value in user.values():
    print(value)

Checking keys

if "name" in user:
    print("We have a name.")

Nested structures

This is the shape of real data — a list of dicts:

students = [
    {"name": "Chisomo", "score": 85},
    {"name": "Tadala", "score": 92},
    {"name": "Gift", "score": 78}
]

for s in students:
    print(f"{s['name']} scored {s['score']}")

Sets — unique collections

colors = {"red", "green", "blue"}
colors.add("yellow")

numbers = [1, 2, 2, 3, 3, 3]
unique = set(numbers)    # {1, 2, 3}

Sets are unordered and automatically remove duplicates. Great for membership checks: if x in my_set is faster than a list.

Dictionaries are the foundation of JSON, which is how almost every API communicates. Master dicts and you're ready for backend work.

Python powers the backend of Instagram, Spotify, YouTube, and thousands of other services. In this lesson, you'll see what a real backend looks like.

What is a backend?

A backend is a program that runs on a server and:

  • Listens for HTTP requests from browsers/apps
  • Reads and writes to a database
  • Returns data (usually JSON)
  • Handles authentication, payments, business logic

Flask — the simplest Python web framework

Flask turns Python functions into web endpoints. Here's a complete Flask app:

from flask import Flask, jsonify, request

app = Flask(__name__)

# An in-memory "database"
tasks = [
    {"id": 1, "title": "Learn Python", "done": True},
    {"id": 2, "title": "Build an API", "done": False}
]

@app.route("/tasks", methods=["GET"])
def list_tasks():
    return jsonify(tasks)

@app.route("/tasks", methods=["POST"])
def add_task():
    data = request.get_json()
    new_task = {
        "id": len(tasks) + 1,
        "title": data["title"],
        "done": False
    }
    tasks.append(new_task)
    return jsonify(new_task), 201

@app.route("/tasks/<int:task_id>", methods=["DELETE"])
def delete_task(task_id):
    global tasks
    tasks = [t for t in tasks if t["id"] != task_id]
    return "", 204

if __name__ == "__main__":
    app.run(debug=True)

What you're looking at

  • @app.route(...) is a decorator — it tells Flask "when someone visits this URL, run this function"
  • The function returns data. Flask automatically converts Python dicts to JSON
  • methods=["GET"] specifies which HTTP verbs are allowed
  • <int:task_id> captures part of the URL as a variable

Running it locally

# In your terminal:
pip install flask
python app.py

# Then visit http://localhost:5000/tasks

Why we can't run Flask here

Flask needs a real network socket and a persistent Python process. This browser editor runs Python in a sandbox without networking. So for this lesson, your exercise is to write the data-handling functions that a Flask route would call — the same logic, just without the HTTP layer.

When you're ready to run real Flask, follow the download link at the bottom of this lesson, install Python on your computer, and try the code above.

What the app does

The plan

  1. Define load_tasks() and save_tasks() using json

Why this project matters

Every backend is the same idea: receive input, process data, persist it, return a result. This CLI app is the smallest complete example of that pattern. When you later move to Flask, you'll see it's the same logic — just with HTTP instead of input().
