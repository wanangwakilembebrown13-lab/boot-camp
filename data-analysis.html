Before we dive into pandas, let's refresh the Python essentials you will use constantly. If you have taken our Python Fundamentals course, this is a fast recap — if you are rusty, slow down.

Variables and types

name = "Chisomo"       # str
age = 22               # int
height = 1.75          # float
is_student = True      # bool

Python infers the type. You can check it with type(x).

Lists — ordered sequences

districts = ["Lilongwe", "Blantyre", "Mzuzu"]
districts.append("Zomba")             # add to end
districts[0]                          # "Lilongwe"
districts[-1]                         # "Zomba"
districts[1:3]                        # ["Blantyre", "Mzuzu"]
len(districts)                        # 4

Lists are mutable — you can change them after creation.

Dictionaries — key-value maps

user = {
    "name": "Chisomo",
    "age": 22,
    "city": "Lilongwe"
}
user["name"]                 # "Chisomo"
user["email"] = "c@m.mw"     # add a key
user.get("phone", "none")    # safe lookup

Dictionaries are the natural shape of one "row" of data. When we load a CSV into pandas, each row becomes a dict internally.

List of dicts — the tabular shape

rows = [
    {"district": "Lilongwe", "population": 1200000},
    {"district": "Blantyre", "population": 1000000},
    {"district": "Mzuzu",    "population": 220000}
]

for row in rows:
    print(row["district"], row["population"])

This is exactly what pd.DataFrame(rows) expects. Remember this pattern — it will appear in every lesson.

Try it

In the sandbox, create a small list of 3 districts with their populations. Print each one on its own line.

Data analysis is 80% "wrangling" — reshaping, filtering, and cleaning data. Python's list and dict primitives are what make wrangling possible.

Loops and functions are the two tools that turn raw data into insight. Every pandas pattern you will learn is built on top of them.

for loops

districts = ["Lilongwe", "Blantyre", "Mzuzu"]

for d in districts:
    print(d)

# with index
for i, d in enumerate(districts):
    print(i, d)

while loops — less common in data work

n = 0
while n < 3:
    print(n)
    n += 1

You will use for far more than while. Data is usually a collection you iterate over.

Functions

def mean(numbers):
    return sum(numbers) / len(numbers)

def describe(name, age):
    return f"{name} is {age} years old"

print(mean([10, 20, 30]))       # 20.0
print(describe("Chisomo", 22))

Functions keep your analysis organized. Instead of a 300-line script, you write small functions that each do one thing.

List comprehensions

A Pythonic shortcut for building lists:

squares = [n * n for n in range(1, 6)]
# [1, 4, 9, 16, 25]

lilongwe_only = [d for d in districts if d == "Lilongwe"]
# ["Lilongwe"]

You will use comprehensions constantly in data work — but only on small collections. For anything large, pandas replaces them.

Conditionals

for d in districts:
    if d == "Lilongwe":
        print(d + " is the capital")
    elif d == "Blantyre":
        print(d + " is the commercial hub")
    else:
        print(d + " is a major city")

Write a function average(numbers) that returns the mean. Test it on a list of 5 numbers. Then use a list comprehension to build a list of the squares of numbers 1–10.

Once you are comfortable with loops and functions, pandas will feel like a superpower — it does in one line what would take you ten with a for loop.

NumPy is the foundation of every Python data tool. pandas is built on top of it. Matplotlib accepts it. SciPy, scikit-learn, PyTorch — all of them use NumPy arrays as the universal data format.

What is a NumPy array?

A NumPy array is like a Python list, but:

  • Faster — 10–100× faster for numerical operations
  • Typed — all elements share the same type (usually float64)
  • Vectorized — you operate on the whole array at once, not element by element
import numpy as np

arr = np.array([1, 2, 3, 4, 5])
print(arr)
print(arr.shape)      # (5,)
print(arr.dtype)      # int64

Creating arrays

np.zeros(5)              # [0. 0. 0. 0. 0.]
np.ones(3)               # [1. 1. 1.]
np.arange(0, 10, 2)      # [0 2 4 6 8]
np.linspace(0, 1, 5)     # [0.   0.25 0.5  0.75 1.  ]
np.random.rand(3)        # 3 random numbers in [0, 1)

arange is like Python's range but returns an array. linspace returns evenly spaced numbers between two values — useful for plotting.

Vectorized operations — the superpower

Without NumPy:

prices = [100, 200, 300]
doubled = []
for p in prices:
    doubled.append(p * 2)

With NumPy:

prices = np.array([100, 200, 300])
doubled = prices * 2          # array([200, 400, 600])

Every arithmetic operator applies to the whole array. Same for comparison, and functions:

a = np.array([1, 2, 3])
b = np.array([10, 20, 30])

a + b       # [11, 22, 33]
a * b       # [10, 40, 90]
np.sqrt(a)  # [1.   1.414 1.732]
a > 2       # [False False  True]

2D arrays

grid = np.array([
    [1, 2, 3],
    [4, 5, 6]
])
grid.shape       # (2, 3)
grid[0]          # [1, 2, 3]
grid[1, 2]       # 6
grid[:, 0]       # [1, 4] (first column)

Try it

Create an array of numbers 1–10. Compute their squares (without a loop). Compute the sum. Print the mean.

If you find yourself writing a for loop over a list of numbers, stop and ask: can this be done with a NumPy array in one line? 99% of the time, yes — and it will be 50× faster.

Two NumPy features make it truly powerful for data analysis: broadcasting and aggregations.

Broadcasting

Broadcasting means NumPy stretches arrays to match shapes when doing arithmetic — automatically.

arr = np.array([1, 2, 3, 4, 5])
arr + 10          # [11, 12, 13, 14, 15]  (10 is broadcast to every element)
arr * 2           # [ 2,  4,  6,  8, 10]

Two arrays of compatible shape:

prices = np.array([100, 200, 300])
taxes = np.array([0.1, 0.1, 0.15])
total = prices * (1 + taxes)
# [110. 220. 345.]

Broadcasting also works with 2D arrays:

matrix = np.array([
    [1, 2, 3],
    [4, 5, 6]
])
row_mean = matrix.mean(axis=1)     # array([2., 5.])
centered = matrix - row_mean.reshape(2, 1)
# subtract the row mean from each row

Aggregations

scores = np.array([85, 92, 78, 95, 88])

scores.sum()      # 438
scores.mean()     # 87.6
scores.min()      # 78
scores.max()      # 95
scores.std()      # 6.13...
np.median(scores) # 88.0

The axis parameter

For 2D arrays, axis controls which direction to aggregate:

grid = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

grid.sum()             # 21      (everything)
grid.sum(axis=0)       # [5, 7, 9]  (down each column)
grid.sum(axis=1)       # [6, 15]    (across each row)
grid.mean(axis=0)      # [2.5, 3.5, 4.5]

Remember: axis=0 collapses rows (aggregates down a column). axis=1 collapses columns (aggregates across a row).

Boolean masking — filtering without loops

scores = np.array([85, 92, 78, 95, 88])

high = scores > 85
# [False  True False  True  True]

scores[high]
# [92, 95, 88]

scores[scores > 85].mean()
# 91.67

This one pattern — arr[arr > threshold] — is used constantly in data analysis.

Try it

Create an array of 20 random numbers between 0 and 100. Compute the mean, min, and max. Then filter the array to keep only numbers greater than 50, and count how many there are.

Broadcasting and boolean masking are the two NumPy concepts you will use most. Master them and pandas will feel natural — pandas reuses both, just with labels on top.

pandas is the single most important library in Python data analysis. It gives you two data structures — Series and DataFrame — that make working with tabular data natural and fast.

What is a DataFrame?

Think of it as a spreadsheet in code. Rows, columns, labels, mixed types. Under the hood, it is a collection of NumPy arrays plus an index.

import pandas as pd

df = pd.DataFrame({
    "district": ["Lilongwe", "Blantyre", "Mzuzu"],
    "population": [1200000, 1000000, 220000],
    "gdp": [850, 920, 780]
})

print(df)

Output:

    district  population  gdp
0   Lilongwe     1200000  850
1   Blantyre     1000000  920
2      Mzuzu      220000  780

From a list of dicts

The most common shape when loading JSON or CSVs:

rows = [
    {"district": "Lilongwe", "population": 1200000},
    {"district": "Blantyre", "population": 1000000},
]
df = pd.DataFrame(rows)

From a CSV file

df = pd.read_csv("data.csv")

That is the most common line of pandas code in the world. It reads a CSV into a DataFrame. In the sandbox, we will build DataFrames from Python data since we do not have real files — but the operations are identical.

Exploring a DataFrame

First five rows:

df.head()

Last five:

df.tail()

Shape, columns, types, missing values:

df.shape        # (rows, columns)
df.columns      # column names
df.dtypes       # data type of each column
df.info()       # summary with non-null counts
df.describe()   # statistics for numeric columns

describe() is usually the first thing you run on a new dataset. It gives you count, mean, std, min, quartiles, and max for every numeric column.

Selecting columns and rows

df["district"]              # one column (a Series)
df[["district", "gdp"]]     # multiple columns (a DataFrame)

df.loc[0]                   # row by label
df.iloc[0]                  # row by position

df[df["gdp"] > 800]         # filter rows

A Series vs a DataFrame

A Series is a single column: one-dimensional, with an index. A DataFrame is a collection of Series sharing the same index. df["district"] returns a Series; df[["district"]] returns a DataFrame.

Try it

Create a DataFrame with 4 cities and columns for city, population, and area. Print df.shape, df.describe(), and then filter to cities with population greater than 500000.

90% of data analysis begins with pd.read_csv(), then df.info() and df.describe(). Get in the habit of those three lines — they tell you what you are working with.

Real datasets are messy. Columns have wrong types, values are missing, labels are inconsistent. pandas gives you the tools to clean and reshape.

Missing values

df.isna()             # boolean mask of missing
df.isna().sum()       # count per column
df.dropna()           # drop rows with any missing
df.fillna(0)          # fill missing with 0
df["gdp"].fillna(df["gdp"].mean())   # fill with mean

There is no universally correct choice. Dropping loses data; filling invents it. The right answer depends on the question you are asking.

Renaming and cleaning text

df.rename(columns={"old": "new"}, inplace=True)
df["district"] = df["district"].str.strip()
df["district"] = df["district"].str.title()
df["district"] = df["district"].str.replace("LILONGWE", "Lilongwe")

String columns have a .str accessor with dozens of useful methods. Cleaning text is 30% of real data work.

Filtering with conditions

df[df["year"] == 2022]
df[df["gdp_per_capita"] > 800]
df[(df["year"] == 2022) & (df["gdp_per_capita"] > 800)]
df[df["district"].isin(["Lilongwe", "Blantyre"])]

Combine conditions with & (and), | (or). Always wrap each condition in parentheses.

Sorting

df.sort_values("population")
df.sort_values("population", ascending=False)
df.sort_values(["year", "district"])

GroupBy — the killer feature

Group rows by a column, then aggregate:

df.groupby("district")["population"].mean()
df.groupby("district")["gdp_per_capita"].max()
df.groupby("year")[["population", "gdp_per_capita"]].sum()

The pattern is always: group by something, pick a column, apply an aggregation.

Multiple aggregations at once:

df.groupby("district").agg({
    "population": "sum",
    "gdp_per_capita": "mean",
    "literacy_rate": "mean"
})

Adding new columns

df["gdp_total"] = df["population"] * df["gdp_per_capita"]
df["literacy_pct"] = df["literacy_rate"] * 100

New columns are created just by assigning. The multiplication is vectorized — pandas applies it to every row at once.

Try it

Build a DataFrame with district, year, and gdp. Group by district and compute the average gdp. Sort the result from highest to lowest.

If you can write groupby and agg fluently, you can answer 80% of real data questions — "average by region", "total by month", "max by category".

Numbers on their own are hard to read. A single chart can replace a page of statistics. Matplotlib is Python's standard plotting library, and it is what you will use for every visualization in this course.

Your first chart

import matplotlib.pyplot as plt

years = [2019, 2020, 2021, 2022, 2023]
population = [17.5, 18.1, 18.7, 19.3, 19.9]

plt.plot(years, population)
plt.show()

Two lines and you have a chart. plot draws the data; show displays it.

The four chart types you will use most

Line plot — trends over time

plt.plot(years, population)
plt.show()

Use when x is time or another ordered sequence.

Bar chart — comparing categories

districts = ["Lilongwe", "Blantyre", "Mzuzu", "Zomba"]
pops = [1200000, 1000000, 220000, 105000]

plt.bar(districts, pops)
plt.show()

Use when comparing values across categories.

Scatter plot — relationship between two variables

gdp = [850, 920, 780, 760]
literacy = [0.82, 0.85, 0.76, 0.72]

plt.scatter(gdp, literacy)
plt.show()

Use when you want to see if two variables are correlated.

Histogram — distribution of one variable

import numpy as np
scores = np.random.normal(70, 12, 200)

plt.hist(scores, bins=20)
plt.show()

Use when you want to see how values are distributed.

Always label your chart

plt.plot(years, population)
plt.title("Malawi Population, 2019–2023")
plt.xlabel("Year")
plt.ylabel("Population (millions)")
plt.show()

A chart without a title and axis labels is a chart nobody can interpret. Always label.

Try it

Create a bar chart of the populations of 5 Malawi districts. Add a title and axis labels. Then create a line chart of the same data.

Charts are arguments. Every chart should answer one clear question. If you cannot state the question in a sentence, you do not yet know what to plot.

Anyone can make a basic plot. Turning it into something a stakeholder would actually read takes a few more lines.

Colors, markers, and line styles

plt.plot(years, population, color="green", marker="o", linestyle="-")
plt.plot(years, gdp, color="blue", marker="s", linestyle="--")
  • color — any named color or hex like "#00c853"
  • marker — "o" (circle), "s" (square), "^" (triangle), "x"
  • linestyle — "-" (solid), "--" (dashed), ":" (dotted)

Grid and legend

plt.plot(years, population, label="Population")
plt.plot(years, gdp, label="GDP")
plt.legend()
plt.grid(True, alpha=0.3)

label names each line; legend() displays the key. grid adds faint gridlines for readability.

Figure size

plt.figure(figsize=(10, 6))
plt.plot(years, population)
plt.show()

Default is 6.4 × 4.8 inches. Bigger is better for detailed data, smaller is fine for slides.

Subplots — multiple charts in one figure

fig, axes = plt.subplots(1, 2, figsize=(12, 4))

axes[0].plot(years, population)
axes[0].set_title("Population")

axes[1].bar(districts, pops)
axes[1].set_title("Population by District")

plt.tight_layout()
plt.show()

subplots(rows, cols) returns a figure and an array of axes. Each axis is a separate chart. tight_layout() prevents labels from overlapping.

Styling tricks worth knowing

plt.style.use("seaborn-v0_8-whitegrid")

plt.xticks(rotation=45)
plt.ylim(0, None)              # start y-axis at 0
plt.axhline(y=1000000, color="red", linestyle="--", label="Threshold")

xticks(rotation=45) angles x labels so they do not overlap. ylim sets the y-axis range. axhline draws a horizontal reference line.

Two variables, one chart

fig, ax1 = plt.subplots(figsize=(10, 5))

ax1.plot(years, population, color="green", marker="o")
ax1.set_ylabel("Population", color="green")
ax1.tick_params(axis="y", labelcolor="green")

ax2 = ax1.twinx()
ax2.plot(years, gdp, color="blue", marker="s")
ax2.set_ylabel("GDP per capita", color="blue")
ax2.tick_params(axis="y", labelcolor="blue")

plt.title("Population and GDP over Time")
plt.show()

twinx() shares the x-axis but gives a second y-axis. Perfect for comparing two series with different scales.

Try it

Create a figure with 2 subplots side by side: a line chart of population over time on the left, and a bar chart of district populations on the right. Give each a title.

The difference between a beginner chart and a professional one is: title, axis labels, legend, and readable sizing. Four additions. Always make them.

Time to build. The capstone is a full data analysis project on a Malawi districts dataset — 40 rows across 8 districts and 5 years, with intentional data-quality problems that you will fix.

The dataset

We have preloaded MALAWI_RAW into the sandbox. It is a list of dicts, each with these fields:

  • district — district name (string)
  • year — 2019 to 2023 (int)
  • population — people (int)
  • gdp_per_capita — USD per person (int, sometimes missing)
  • literacy_rate — 0 to 1 (float, sometimes missing)
  • maize_tonnes — annual maize production (int)

We intentionally introduced three data-quality problems:

  1. Inconsistent district names — some rows say "LILONGWE", "lilongwe", or "Blantyre " (with a trailing space)
  2. Missing values — a few rows have None for literacy_rate or gdp_per_capita
  3. A duplicate row — the first Lilongwe 2019 row is repeated

The plan

  1. Load MALAWI_RAW into a DataFrame
  2. Inspect with head(), info(), describe()
  3. Fix the district name inconsistencies
  4. Remove the duplicate row
  5. Handle the missing values

Step 1: Load the DataFrame

import pandas as pd

df = pd.DataFrame(MALAWI_RAW)
print(df.head())
print(df.info())
print(df.describe())

The info() output tells you immediately which columns have missing values — the "non-null count" will be lower than the total row count for those columns.

Step 2: Fix district names

Three operations, in order:

# Normalize case and strip whitespace
df["district"] = df["district"].str.strip().str.title()

# Now "LILONGWE" -> "Lilongwe", "lilongwe" -> "Lilongwe", "Blantyre " -> "Blantyre"

.str.title() capitalizes the first letter of every word and lowercases the rest. .str.strip() removes leading and trailing spaces.

Step 3: Remove duplicates

print("Before:", len(df))
df = df.drop_duplicates()
print("After:", len(df))

drop_duplicates() removes rows that are identical across all columns. Use subset=["district", "year"] to remove rows that are duplicates on only a few columns.

Step 4: Handle missing values

Two reasonable approaches for numeric columns:

# Option A: drop rows with any missing
df_dropped = df.dropna()

# Option B: fill with the column mean
df_filled = df.copy()
df_filled["gdp_per_capita"] = df_filled["gdp_per_capita"].fillna(
    df_filled["gdp_per_capita"].mean()
)
df_filled["literacy_rate"] = df_filled["literacy_rate"].fillna(
    df_filled["literacy_rate"].mean()
)

For a small dataset, filling with the mean is usually the safer choice — you keep more rows. We will use that approach in the capstone.

Try it

Load MALAWI_RAW, fix the district names, drop duplicates, and fill missing values. Then print df.shape and df.head() to see the cleaned result.

Data cleaning is not glamorous. It is the actual work. Every analyst spends more time cleaning than analyzing. Get it right and the analysis writes itself.

Your data is clean. Now the interesting part: extract insights and visualize them.

Step 1: Group by district

The most common aggregation in any analysis:

summary = df.groupby("district").agg({
    "population": "mean",
    "gdp_per_capita": "mean",
    "literacy_rate": "mean",
    "maize_tonnes": "sum"
})

print(summary)

You now have one row per district, with the average population, average GDP, average literacy, and total maize production.

Step 2: Add a derived column

Total GDP = population × gdp per capita:

df["gdp_total"] = df["population"] * df["gdp_per_capita"]

district_gdp = df.groupby("district")["gdp_total"].sum()
print(district_gdp.sort_values(ascending=False))

Step 3: Trend over time

yearly = df.groupby("year")[["population", "gdp_per_capita", "maize_tonnes"]].mean()
print(yearly)

Step 4: Visualize — chart 1: population by district

import matplotlib.pyplot as plt

summary_sorted = summary.sort_values("population", ascending=False)

plt.figure(figsize=(10, 6))
plt.bar(summary_sorted.index, summary_sorted["population"])
plt.title("Average Population by District")
plt.xlabel("District")
plt.ylabel("Population")
plt.xticks(rotation=45)
plt.show()

Step 5: Chart 2 — GDP trend over time

plt.figure(figsize=(10, 5))
plt.plot(yearly.index, yearly["gdp_per_capita"], marker="o", color="green")
plt.title("Malawi Average GDP per Capita, 2019–2023")
plt.xlabel("Year")
plt.ylabel("GDP per Capita (USD)")
plt.grid(True, alpha=0.3)
plt.show()

Step 6: Chart 3 — GDP vs literacy scatter

plt.figure(figsize=(8, 6))
plt.scatter(summary["gdp_per_capita"], summary["literacy_rate"], s=80)
plt.title("GDP per Capita vs Literacy Rate")
plt.xlabel("GDP per Capita (USD)")
plt.ylabel("Literacy Rate")
for name, row in summary.iterrows():
    plt.annotate(name, (row["gdp_per_capita"], row["literacy_rate"]), fontsize=9)
plt.show()

annotate places text at a specific point — here, the district name next to its dot. Essential for scatter plots with categories.

Step 7: Write your insights

Three sentences that answer real questions:

  • Which district has the highest average GDP per capita? Which has the lowest?
  • Is GDP trending up or down over the 5 years?
  • Is there a visible relationship between GDP and literacy? What does that suggest?

Add these as a print() block at the end of your script:

top = summary["gdp_per_capita"].idxmax()
bottom = summary["gdp_per_capita"].idxmin()

print()
print("=== Insights ===")
print(f"Highest GDP per capita: {top}")
print(f"Lowest GDP per capita: {bottom}")
print(f"GDP growth 2019-2023: {(yearly['gdp_per_capita'].iloc[-1] / yearly['gdp_per_capita'].iloc[0] - 1) * 100:.1f}%")
